BUILDING: FULL vs SELECTIVE
    colcon build) builds every package in src/ --> FIne for small workspaces
    coclcon build --packages-select <pkg_name>) builds only the packages you named
        **Use for more than 2-3 packages
    colcon build --symlining-install) symlinks python files instead of copying them
        **Use so you don't have to call colcon again for .py files 


SOURCING: MAKING THE WORKSPACE VISIBLE)
    Building must be accompanied with sourcing so that your shell knows the workspace exists

    source install/setup.bash overlays your workspace on top of the base ROS2 install
        **If a file cannot be found, you forgot to source after Rebuilds

    
RUNNING TESTS AND CHECKING RESULTS
    colcon test) Runs any tests defined in your packages
    colcon test-result --verbose) prints a readable pass/fail summary
    colcon list) shows every package colcon can see in your workspace
