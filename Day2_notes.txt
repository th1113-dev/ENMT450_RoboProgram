CENTRALIZED VERSION CONTROL SYSTEMS

    - There is a singler, central server that stores all versions of the projects flies

    - Only the latest versions are stored locally on a machine

    - CHARACTERISTICS

        b) The entire history of the software is on the central server


DISTRIBUTED VERSION CONTROL SYSTEMS

GIT - A DVCS

    - The workflow revolves around managing changes in your working directory, staging area, and the repositorys history

    - Old versions of files are hidded in a folder called .git

    - Cannot change binary files (Ex. CAD files)

    -COMMANDS
        a) git init
            Enables Git into a certain repository (making it a Git repo)

        b) git add <file>
            Used to stage files, marking the changes you want to include in the next snapshot/commit

        c) git commit
            Creates a snapshot of the currently staged changes, recording them in the repos history. Each commit includes metadata like the author, timestamp, and a descriptive message

        d) git status
            Use the command to see the surrent stat of your working directory, including staged, unstaged, and utracked changes

        e) git log
            The command shoes the commit history 
                git lol shows it in ASCII art

        f) git diff
            See what changes were made

        g) git clone <URI of remote repo> <project name>
            Makes full copy of a repo onto the local machine
        
        h) git push <remote name> <branch name>
            Pushes your changes into its own branch
                **Works without the remote or branch name too (git push)

        i) git pull
            Updates all changes and merges them into local repo [DO THIS OFTEN]

        j) git checkout -b <New branch name>
            Creates a new branch and switches to it

        k) git checkout <branch name>
            use to switch in between branches

        l) git merge <branch to merge>
            Merges branches together 
        
        m) git merge --fast-forward
            Git moves the branch pointer forward if there are no diverging changes
        
        n) git rebase <target-branch>
            moves the base of a branch to be a different commit # [DO NOT TO TO OTHER PEOPLES BRANCHES]

        o) git cherry-pick <commit-ID>
            Copies a specific commit from one branch to another branch
