                                    ---------- Intro to The Command line ----------
-UNIX/LINUX Command line
    pwd) print working directory

    ls) List directories and files in the current location
        -l) list mode
        -a) all (Shows hidden)

    cd) change directory
        ..) from the parent directory
        .) from current directory
        ~) to home 
        //) from root

    mkdir) make directory

    touch) create files
    
    cp or mv) copy files
        ** mv moves files as well

    rm) remove files
        -r) delete this shit NOW

    rmdir) remove directory

    cat & less) Print out the entire file into the command line
        ** less opens it in another window/pages

    head & tail) inspect files at either the end or beginning 
        ** You can choose how many you see
    
    nano / micro) inline text-editor

    Pipeline - |) pipeline connects stdout of one program directlu into stdin of another 
    
    Overwrite - >) redirect output to create or overwrite a target file
    
    Append - >>) append output to the end of an existing file without cestroying content

    grep) search text streams instantly using key phrases or regex patterns

    wc -l) count lines, words, or bytes produced by any upstream command 

    sort | uniq -c) sort lines and count or isolate duplicate frequency entries

    awk) Modify a file based on a series of expression
        ** it is a separate programming language designed for text processsing and data extraction

        print) outpit specific fields o rlines
            ex) awk '{print $1, $2}' file.txt
                ** print field one and two of file.txt
        
        pattern matching) process lines matching a pattern 
            ex) awk '/pattern/ {print $0}' file.txt

        filed separator) specify a custom field separator 
            ex) awk -F, '{print $1}' file.csv

        sum a column)
