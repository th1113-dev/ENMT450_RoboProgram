BUILDING A WS WITH COLCON
    Colcon is a multi-package build tool

    It iterates through all packages in src/, computes the topological build dependencies, and compiles in parallel

    It uses the Ament build system to rebuild
 
    Essential command sequence:
        cd ~/ros2_ws
        colcon build
        colcon build --symlink-install
