-FROM DESKTOP TO ROBOTIC CONTROL
    There are general OS' and RTOS' where there are different tradeoffs for them to be individuals and also to work with eachother
        * results in non-deterministic processes to occur (Jitter)
            ~ makes things with high rates of control unusable on these systems
    RT and Robotic OS' are designed for hard latency guaruntees with little to no jitter
        * Prioritizes function over GUI for example

    Windows dominates the factory PLC setups and automation software
        * Closed-source API restricted low-level timing mods.

    macOSx has a comfortable environmemt for users while allowing for software usage capability
        * Strict hardware lock-in and driver signing created friction for hardware sensor IO

    Linux is opensource and real-time patches can be made (PREEMPT_RT)
        * Open modular kernel enabled Willow Garage to build ROS natively on Ubuntu in 2007


-OS LIMITATIONS CREATED FOR ROBOTICS PROGRAMMING
    1) Kernel Preemption and jitter
        Kernel delays interrupt execution to favor CPU throughput
            * Intruduces latency spikes

    2) Peripheral Driver Lock-in
        LiDARs, CAN buses, and robotic arms rely on low-level C++ drivers compiled strictly for specific OS Kernel ABI Versions

    3) Distribution dependancy coupling
        Early ROS 1 releases tied distros strictly to Ubuntu LTS versions.
            * Freezes system updates

-INTRO TO HYPERVISORS
    A software layer that enables virtualization bu allowing multiple OS' to run on a single physical machine

    Types:
        1: Bare-Metal) Runs directly on hardware
            ex. VMware ESXi, Microsoft Hyper-V

        2: Hosted) Runs on a host OS
            ex. VMware Workstation, Oracle VirtualBox

    Functions:
        a) Resource management: Allocates physical resources to VMs
        b) Isolation: Ensures each VM operates independentlu without interference
        c) Performance Optimization: Manages VM performance and efficiency

    Hardware virtualization:
        Refers to the use of computer harware to support the creation and management of virtual machines more efficiently

    Key tech:
        Intel VT-x is for x86 processors, providing hardware extensions for improved VM performance

        AMD-V offers something similar

-CONTAINERIZATION
    Lightweight form of virtualization that packages and app and its dependencies into a single container

    Ensures that apps run consistently across different computing env.

    They run in isolated env. but share the host OS

    Slower but saves more storage and allows for a program to be isolated from others on different devices

    It's portable 

    Orchestration:
        Automates the deployment, scaling, and management of containerized apps
